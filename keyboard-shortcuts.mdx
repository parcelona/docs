Everything in Parcelona works from the keyboard. Press **⌘/** in the app to see every shortcut.

## Listings

| Keys | Action |
| --- | --- |
| **⌘T** | New listing |
| **↵** | Continue to the next step |
| **⌘[** | Go back |
| **↑ ↓** or **Tab** | Move through options |
| **Space** | Toggle an option |
| **1–5** | Pick an option by number |
| **⌘D** | Draft anyway, when Claude has a question |
| **⌘↵** | Post |
| **⌘S** | Save as draft |
| **⌘E** | Archive the listing |
| **⇧⌘E** | Show or hide the archive |

## Window

| Keys | Action |
| --- | --- |
| **⌘W** | Close tab |
| **⌘1–9** | Go to a tab |
| **⇧⌘[** / **⇧⌘]** | Previous or next tab |
| **⌘,** | Settings |
| **⌘/** | Show all shortcuts |
